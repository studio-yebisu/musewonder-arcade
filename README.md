# MUSE ARCADE

ブラウザだけで遊べる、4つのカジュアルゲームを収録した小さなアーケードです。ビルド不要・依存パッケージなし・外部通信なしで動作します。

## 収録ゲーム

| ゲーム | ジャンル | 目的 |
| --- | --- | --- |
| BLOCK STACK | 落ちものパズル | 横一列をそろえてラインを消し続ける |
| PRISM BREAK | ブロック崩し | 全3ステージのブロックをすべて崩す |
| STAR DRIFT | 縦シューティング | WAVE 6 のボス大型艦を撃破する |
| MIDNIGHT RUN | レース | 80秒以内に 3000m 先のゴールへ到着する |

ベストスコアとサウンド設定は `localStorage` に保存され、**この端末の中だけで**保持されます。オンラインランキングはありません。保存できない環境ではメモリ上に切り替えて動作を続けます。

## 操作方法

共通: `P` / `Esc` で一時停止・再開。画面上のボタンでも一時停止・最初から・一覧に戻る操作ができます。タブを切り替えると自動で一時停止します。

### BLOCK STACK（落ちものパズル）

- `←` `→`: 移動（長押しで連続移動）
- `↓`: ソフトドロップ
- `↑` または `X`: 回転 / `Z`: 逆回転
- `Space`: ハードドロップ
- `C`: ホールド（1ピースにつき1回）
- タッチ: 画面下のボタン（移動・回転・落下・ホールド）

### PRISM BREAK（ブロック崩し）

- `←` `→` / マウス / 指のドラッグ: パドル移動
- `Space` / タップ / 発射ボタン: ボール発射
- 数字付きの堅いブロックは2回当てると壊れます。ライフは3つです。

### STAR DRIFT（縦シューティング）

- 方向キー / `WASD` / 画面ドラッグ / 方向ボタン: 移動
- ショットは自動発射です。HPは3、被弾直後は短時間無敵になります。

### MIDNIGHT RUN（レース）

- `←` `→`: ステアリング
- `↑`: アクセル / `↓`: ブレーキ
- 操作しなくても巡航速度までは自動加速します。カーブでは外側へ流れるので早めに切ってください。接触・路肩走行は減速します。

## ローカルで動かす

`dist/index.html` を静的サーバーで配信してください（ES モジュールを使うため、ファイル直開きではなく http 経由を推奨します）。

Python の場合:

```bash
cd dist
python -m http.server 8000
# http://localhost:8000/ をブラウザで開く
```

Node.js の場合（追加インストール不要の簡易確認には Python 方式が簡単です）:

```bash
cd dist
npx serve .
```

## GitHub Pages での公開

アセット参照はすべて相対パス（`styles.css`、`main.js`、`./core/...` など）で書かれているため、ドメイン直下（`/`）でもプロジェクトページ（`/musewonder-arcade/` のようなサブパス）でもそのまま動作します。

公開版は GitHub Actions から `dist/` を配信します。Settings → Pages の Source は **GitHub Actions** を選びます。公開用リポジトリの `.github/workflows/pages.yml` は構文チェックと操作ロジックのテストを実行し、成功した版を配信します。公開ブランチ `codex/arcade` の更新で再配信できます。

## 開発者向け

- 構成: `dist/core/`（storage / audio / input / runtime）、`dist/games/`（ゲームごとのエンジン）、`dist/main.js`（ライブラリとライフサイクル）
- 診断: ブラウザコンソールで `arcadeDebug.getSnapshot()` を呼ぶと、現在のゲーム・状態・スコアなどの読み取り専用スナップショットが得られます。
- 構文チェックとテスト（Node.js 標準機能のみ、インストール不要）:

```bash
npm run check
npm test
```
